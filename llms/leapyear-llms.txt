# LeapYear

> LeapYear Technologies built an enterprise platform for differentially private analytics and machine learning. Organizations pointed it at their most sensitive data and ran statistics, SQL-style queries, feature engineering, and model training while a mathematically provable privacy guarantee bounded what any single record could leak. The product shipped as a self-hosted server, LeapYear Core, driven by a first-party Python client. Snowflake acquired LeapYear in February 2023 for $62.0 million in cash and folded the technology into the Data Cloud's clean-room capabilities. The standalone surface is retired.

Status: acquired by Snowflake, 2023-02-10. leapyear.io no longer answers on HTTPS. The only reachable public developer surface is the hosted Python client reference for version 4.1.1.

## APIs

- [LeapYear Python Client](https://leapyear-python-docs.readthedocs-hosted.com/en/4.1.1/): First-party Python library for LeapYear Core. Self-hosted only — there is no public multi-tenant endpoint. The client is pointed at a customer-operated server via the `url` argument or the `LY_API_URL` environment variable.

## Notes for agents

- There is no OpenAPI, AsyncAPI, GraphQL, gRPC, MCP server, CLI, sandbox, changelog, status page, or public package for LeapYear. None were ever published, and the company surface is now retired. Do not synthesize them.
- Privacy budget, not request volume, is the metered resource. A computation can be refused outright when its estimated Privacy Exposure would breach the configured limit, and the reason is deliberately withheld because the reason itself could leak information.
- For current differential privacy capability, look to Snowflake, which acquired this technology.
